隱私資訊聲明

說明本網站如何處理您的資訊。

1. 網站本身不蒐集個人資料

本網站為靜態網站，沒有會員帳號、線上表單或資料庫，不使用 Cookie、網站分析或追蹤工具，亦不載入第三方廣告或社群外掛。

證書查詢之搜尋與篩選在您的瀏覽器中執行，不會將查詢內容傳送給 AISML。篩選條件會顯示在網址中以便分享；開啟含條件之網址時，網址會依一般網站運作方式傳送至網站主機。

2. 網站主機紀錄

本網站由 GitHub Pages 代管。依 GitHub 說明，GitHub 為安全目的記錄訪客之 IP 位址，不論訪客是否登入 GitHub。該紀錄由 GitHub 依其隱私權聲明處理及保存，AISML 不取得、亦不另行保存網站連線紀錄。

3. 以電子郵件提供之個人資料

您寄信至 Service@aisml.org.tw 時，會提供姓名、聯絡方式及信件內容等個人資料。依個人資料保護法第 8 條，告知如下：

  • 蒐集者：明志科技大學（由電機工程系人工智慧資安管理系統研究室 AISML 執行）。
  • 蒐集目的：回覆資訊請求，處理驗證申請之洽詢、申訴及抱怨。
  • 個人資料類別：姓名、電子郵件、電話等聯絡方式，以及您於信件中提供之內容。
  • 利用期間、地區、對象及方式：自收到信件之日起保存 5 年，期滿刪除；期間由 AISML 人員以電子郵件或書面方式，於中華民國境內利用。除法律另有規定或經您同意外，不提供予第三人。
  • 您的權利：您得向明志科技大學請求查詢、閱覽、製給複製本、補充或更正、停止蒐集、處理或利用，以及刪除您的個人資料。
  • 不提供之影響：您可自由選擇是否提供；未提供必要之聯絡資訊時，AISML 可能無法回覆或處理您的請求。

申訴及抱怨之提出人與內容，依 AISML〈管理系統驗證機構公開聲明書〉之保密承諾處理。

4. 聯絡

對本聲明或您的個人資料有任何問題，請寄信至 Service@aisml.org.tw；亦可參閱明志科技大學〈個人資料保護管理政策聲明〉，或洽個資保護聯絡窗口。
