Information Security Statement

The security measures of this website and how to report security issues.

1. Website architecture

This website is a static website: pages are generated in an offline environment before being published, and the website has no application server, database, member accounts or online forms, which reduces the risk of injection attacks and data leakage. Website content is managed under version control, and every change is recorded.

2. Security measures

  • No third-party scripts, fonts or tracking tools are loaded; all icons and code used are published with the website.
  • No cookies are used, and none of your data is stored in your browser.
  • The website is hosted on GitHub Pages, and all connections are encrypted using HTTPS.

3. Certificate information

The information listed in Certificate Search is updated in accordance with certification decisions. To confirm the current status of a specific certificate, please email Service@aisml.org or contact the certification body that issued the certificate.

4. External links

This website may link to other websites; the content and security of those websites are the responsibility of the organizations that operate them.

5. Email

Ordinary email may not be encrypted in transit. Please do not send passwords or other highly sensitive information by email; confidential information required for certification activities should be transmitted by the means agreed between the parties.

6. Reporting security issues

If you discover a security issue on this website, please email Service@aisml.org, describing the issue and how to reproduce it. Please do not access, modify or delete data that does not belong to you, or carry out tests that affect the website’s services.

This English version is provided for reference. If there is any discrepancy, the Traditional Chinese version prevails.
