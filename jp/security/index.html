情報セキュリティに関する声明

本ウェブサイトのセキュリティ対策と、セキュリティ上の問題の報告方法について説明します。

1. ウェブサイトの構成

本ウェブサイトは静的なウェブサイトです。ページはオフライン環境で生成したうえで公開しており、ウェブサイト上にはアプリケーションサーバー、データベース、会員アカウントおよびオンラインフォームがないため、インジェクション攻撃や情報漏えいのリスクを低減できます。ウェブサイトのコンテンツはバージョン管理されており、変更のたびに記録が残ります。

2. セキュリティ対策

  • 第三者のスクリプト、フォントまたはトラッキングツールは読み込みません。使用しているアイコンおよびプログラムは、すべてウェブサイトとともに公開しています。
  • Cookie は使用せず、利用者のデータをブラウザに保存しません。
  • 本ウェブサイトは GitHub Pages でホスティングされており、通信はすべて HTTPS で暗号化されます。

3. 認証書に関する情報

認証書検索に掲載している情報は、認証の決定に基づいて更新されます。特定の認証書の最新の状態を確認する必要がある場合は、Service@aisml.org までメールでお問い合わせいただくか、当該認証書を発行した認証機関にお問い合わせください。

4. 外部リンク

本ウェブサイトは他のウェブサイトにリンクする場合があります。それらのウェブサイトの内容およびセキュリティについては、各ウェブサイトの運営者が責任を負います。

5. 電子メール

一般的な電子メールは、送信の過程で暗号化されていない場合があります。パスワードその他の機密性の高い情報を電子メールで送信しないでください。認証活動に必要な機密データは、双方で合意した方法でお送りください。

6. セキュリティ上の問題の報告

本ウェブサイトのセキュリティ上の問題を発見された場合は、問題の内容と再現手順を記載のうえ、Service@aisml.org までメールでお送りください。ご自身に属さないデータへのアクセス、改変もしくは削除、またはウェブサイトのサービスに影響を及ぼすテストは行わないでください。
