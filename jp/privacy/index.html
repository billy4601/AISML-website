プライバシーに関する声明

本ウェブサイトにおける利用者の情報の取扱いについて説明します。

1. ウェブサイト自体による個人情報の収集はありません

本ウェブサイトは静的なウェブサイトであり、会員アカウント、オンラインフォームおよびデータベースはありません。Cookie、アクセス解析ツールまたはトラッキングツールは使用せず、第三者の広告やソーシャルプラグインも読み込みません。

認証書検索での検索および絞り込みは利用者のブラウザ内で実行され、検索内容が AISML に送信されることはありません。絞り込み条件は共有しやすいよう URL に表示されます。条件を含む URL を開いた場合、その URL は一般的なウェブサイトの仕組みに従ってウェブサイトのホストに送信されます。

2. ウェブサイトのホストによる記録

本ウェブサイトは GitHub Pages でホスティングされています。GitHub の説明によれば、GitHub はセキュリティ上の目的で、GitHub へのログインの有無にかかわらず、訪問者の IP アドレスを記録します。この記録は GitHub がそのプライバシーステートメントに従って取り扱い、保存するものであり、AISML がウェブサイトへの接続記録を取得したり、別途保存したりすることはありません。

3. 電子メールで提供される個人情報

Service@aisml.org にメールを送信される際には、氏名、連絡先およびメールの内容などの個人情報をご提供いただくことになります。個人資料保護法（台湾）第8条に基づき、以下のとおりお知らせします。

  • 収集者：明志科技大学（電機工程学系 AIセキュリティマネジメントシステム研究室（AISML）が実施）。
  • 収集の目的：情報の請求への回答、ならびに認証申請に関するお問い合わせ、異議申立ておよび苦情への対応。
  • 個人情報の種類：氏名、電子メールアドレス、電話番号などの連絡先、およびメールでご提供いただいた内容。
  • 利用の期間、地域、対象および方法：メールを受信した日から5年間保存し、期間満了後に削除します。保存期間中は、AISML の要員が電子メールまたは書面により、中華民国（台湾）の域内で利用します。法令に別段の定めがある場合またはご本人の同意がある場合を除き、第三者に提供することはありません。
  • ご本人の権利：ご本人は明志科技大学に対し、ご自身の個人情報について、照会、閲覧、複製物の交付、補充または訂正、収集・処理・利用の停止、ならびに削除を請求することができます。
  • 提供しない場合の影響：提供するかどうかはご本人の任意です。必要な連絡先が提供されない場合、AISML はご請求に回答または対応できないことがあります。

異議申立ておよび苦情の申立人とその内容は、AISML の「マネジメントシステム認証機関 公開声明書」に定める機密保持のコミットメントに従って取り扱います。

4. お問い合わせ

本声明またはご自身の個人情報についてご質問がある場合は、Service@aisml.org までメールでお問い合わせください。また、明志科技大学の「個人情報保護管理方針に関する声明」をご参照いただくか、個人情報保護の連絡窓口にお問い合わせください。
